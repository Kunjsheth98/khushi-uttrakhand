🔧 Firebase Setup Needed — Read This First

To sync lists between everyone's phones, follow these steps (takes ~5 minutes):

1. Go to console.firebase.google.com → Sign in → Create project named mittal-yatra-2026
2. Inside project → Click "Firestore Database" → Create database → Choose test mode → Pick asia-south1 (Mumbai) region
3. Go to Project Settings (⚙️ icon) → "Your apps" → Click </> → Register app → Copy the firebaseConfig object
4. Open index.html in any text editor → Find the firebaseConfig object near the bottom → Replace each YOUR_... value with yours
5. Save & push to GitHub Pages — all three of you will see each other's items in real-time! 🎉
⚡ Until Firebase is set up, items save only on this device (not shared). The app still works fully offline!
